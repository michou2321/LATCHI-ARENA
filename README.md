# Latchi Arena

غلاف أصلي (native) لموقع **arena.ai** — كل مزايا الموقع داخل تطبيق أندرويد حقيقي.

**تحميل:** https://github.com/michou2321/LATCHI-ARENA/releases/latest/download/LatchiArena-1.0.0.apk

## المزايا
- محادثة · اختيار موديل · مقارنة · تصويت · سجل
- رفع الصور والملفات · تحميل الملفات
- تسجيل الدخول داخل التطبيق
- سحب للتحديث · زر رجوع ذكي · نسخة سطح المكتب

```bash
cd android && gradle assembleRelease
```
أو GitHub Actions تلقائياً على كل push.
